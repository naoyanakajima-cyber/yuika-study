# 教材案JSONの非同期読み込み保護

2026-11-14。PdMが整理しPrMが採択した、教材確認室（CONTENT-MVP）の作業保全仕様。
画像/テキスト教材を追加する前段で、読み込み待ちの間に直した問題案や確認状態を守る。
保存しない試し解き本体、採点、試行回答、BFCacheでの試行消去は今回実装しない。

## 動作契約

- 取込ごとに識別子を発行し、開始時の案作業世代を捕捉する。新しい取込だけが結果、失敗表示、pending表示、ファイル入力の後始末を変更できる。
- 内容編集、別サンプル採用、案取消、個別確認、JSON出力が成立したら案作業世代を進める。確認や出力では案JSONのrevisionを増やさない。古い読み込み結果は採用せず、案が変わったため再入力が必要と案内する。
- 新しい取込の失敗・構造不正・200KB超過でも現在案を保持し、それ以前の取込を復活させない。採用直前にも世代と従来の未保存案の破棄確認を検査し、破棄確認の拒否で案・revision・確認・unsavedを変えない。
- 読み込み中も編集・確認・出力はできる。読み込み中の状態表示と「読み込みを取り消す」を提供する。明示取消または空filesのchangeは取込だけを無効化し、現在案を保持する。明示取消後はファイル入力へフォーカスを戻す。
- ネイティブファイル選択ダイアログがchangeを送らず閉じた場合の検出は保証しない。その場合、進行中表示と明示取消を使用する。同じファイルを再選択できるよう最新取込の終了時だけ入力を空にする。
- 再入力したJSONの全問はdraft、confirmedRevisionはnullへ戻す。schema、出典検査、内容変更時revision更新/全確認失効、未確認/確認済みJSONの形式は維持する。
- 追加状態はメモリだけ。storage、cookie、URL/history、外部通信・通知への書込みは増やさず、JSONへ世代やpendingを追加しない。CSP、既存学習6画面、採点・問題ID・保存形式・親runtimeは変更しない。親検査の例外は当該HTMLの固定SHA256だけ更新し、独立QAでmemory-onlyを再確認する。

## 検証

合成入力だけを使用する `tests/content_import_guard.py` を必須 `scripts/check_all.sh` に追加。
実ファイル入力/編集DOMを操作し、File.textのPromise解決順を制御して以下を検査する。

- 読込み待ち→編集・確認・出力・別サンプル・案取消→後着結果で、作業とunsavedを保持。
- A/B両方の完了順、旧取込の失敗、最新の不正JSON/読込失敗/サイズ超過で、新取込の入力・pending・noticeと現在案を保持。
- 明示取消、空files change、未保存案の破棄確認拒否、案なしからの正常入力、全確認のリセット。
- 768×1024 Chromiumの実DOM操作、storageメソッド非書込み、許可したloopback GET以外の要求0、pageerror0。

実機のファイル速度やネイティブ選択ダイアログ取消を再現した主張ではない。Safari/WebKit・実iPad互換をこのChromium試験で保証しない。必須全suiteは固定clean HEADで独立QAが実行し、その結果を運用台帳とPRへ保存する。

修正前の固定基点 f1e84a7 では、合成読込み待ち中の問題文編集が後着結果の採用で消えることを再現した（破棄確認承諾時）。修正後は案作業世代の相違により採用しない。
