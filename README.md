# yuika-study

## 天気／日本の地形・気候

学習帳 `index.html` の理科「天気」と社会「日本の地形・気候」から開けます。各単元に基本10問＋標準5問の復習クイズと、基本用語10枚の暗記カードを追加しています。小5・中学受験向けのオリジナル問題で、特定の教材の転載ではありません。

標準問題では、気温・降水量の表の読み取り、雲や冬の雪のでき方の並べ替え、地形と気候の関係などを扱います。表は学習用の仮のデータであり、観測していない時刻の最高気温や実際の都市を断定しない解説にしています。

既存のクイズ・暗記カードと同じ記録形式を使い、単元IDは `rika-weather` と `shakai-japan-land-climate` です。問題や学習記録の既存IDは変更しません。新単元の暗記カードは、読みなどの登録した別表記も認めますが、部分一致は正解にしません。クイズは既存と同じく終了時の集計を保存し、個々の選択内容やヒントなしの正答率は記録しません。ヒントは常時表示されるため、正答率だけで習熟度を断定しないでください。

## 理科の復習アプリ

- [理科ノートを開く](https://naoyanakajima-cyber.github.io/yuika-study/yuika-review-v2.html)
- [記録の保存・引きつぎ手順](science-records-guide.md)

iPadではSafariで開き、「共有」→「ホーム画面に追加」で使えます。学習記録は利用するブラウザー内に保存されます。端末間の自動同期はありません。

既存の学習アプリは `index.html` のままです。理科は別の保存キーを使います。

## 社会 540-24「貴族の世の中」

[新単元を開く](https://naoyanakajima-cyber.github.io/yuika-study/heian-review.html)。既存の学習帳の社会一覧からも開けます。

暗記50問、まぎらわしいペア10問、歴史の流れ10問、理由の練習5問を、5問／10問ずつ練習できます。通常練習では読みも認め、漢字・正式名の確認では登録した表記と照合します。名前の部分一致は正解にしません。自由記述は自動採点せず、並べ替え・穴埋めの結果と分けて保存します。

記録は新しいキー `yuika-social-540-24-v1` に保存し、既存単元・理科のキーは変更しません。新単元内の「保護者のノート」で個別回答と集計、「記録の保存」でJSON入出力と分析用TXT出力を利用できます。初回は履歴記録開始後の初回であり、本当の初回学習とは限りません。通常練習と漢字確認は別集計です。

iPadのSafari・ホーム画面からの起動・別端末では保存領域が異なる場合があります。切り替える前にJSONを保管してください。１つのタブで学習し、定期的に書き出すことをおすすめします。自動メールに接続した場合だけ、チャレンジ結果を保護者へ送ります。


## チャレンジごとの自動メール

社会・理科の結果通知に対応しています。初期状態では無効です。Cloudflare WorkersとResendの接続設定後、ページ下部から保護者が有効にします。失敗時は保留し、次回起動時などに同じ通知IDで再試行します。送信先・APIキーは公開HTMLには保存しません。
