# CEOチェックの1実行

日本語で、CEOが短時間で判断できる報告を作る。
GitHubの最新 `codex/agent-team-operations` branchから `ops/board.json` と
`docs/agent-team.md` を読み、関連PRの現在HEAD・状態・検証結果を照合する。
可能なら開発サイクルautomationの直近結果を読み、登録済みと実行成功を区別する。

`ops/CEO_REPORT.md` の5項目を使い、判断事項は最大3件。
成果・判断・次の仕事・障害・運用状況を簡潔にする。
変更がなくても朝夕のチェックでは現在状態を短く報告する。
実装や長時間テストをこの報告処理で開始せず、台帳を更新しない。
個人の学習記録や教材画像をGitHubから探さない。メール/Slack/Chatへ別送しない。
承認が必要なら具体的な対象・選択肢・推奨案を出し、返事なしで適用しない。
判断はこの運用を設定したCEOチャットへ、チケットIDを添えて返信するよう案内する。
返答を実際に読める担当が台帳へ取り込むまで、workerへ伝達済みとは報告しない。
読み取れない情報は未確認と記し、前回と同じ根本障害の調査を反復しない。
